	🔸> The certain arguments that contains default values is called defalut arguments
	🔸> We can ommit passing default arguments values
	🔸> Useful to make function flexible
	
	 🔸>We must place the defualt arguments at the last in parameters list
	 
	         def timer(start = 0, remind="msg", stop, message)
	 🔸> if we place like this it will generates error in arguments ommiting time.

✅KeyWord Arguments:
   	The arguments that are called by specifying argument name is called keyword arguments
   	🔸> Order of the keyword arguments is does not matter
   	🔸> Narmal arguments must be called&declared at the starting
   	🔸> Keyword arguments must be called&declared at the last
